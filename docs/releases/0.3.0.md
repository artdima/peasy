- Peasy now works with Claude through a built-in MCP server. Claude adds the tasks only you can do, with a note and a link, and Claude Code puts them in the project named like its folder.
- Hand a task to Claude with `@claude` in its title or Hand to Claude in its menu. Claude marks it as in progress, then finishes it with a note or hands it back with a question.
- Tasks show their notes. Choose Note… in a task's menu to write your own.
- Claude has its own tab in Settings. It shows whether Claude Code or Claude Desktop is connected, lets Claude read only or make changes and picks the Claude notifications you get.
- The sprout and the project counts leave out the tasks handed to Claude.
- The + next to Settings in the panel opens the quick add window.
- Drag the panel’s left or bottom edge to resize it, not only its corner.
- A task row no longer shows a copy button on hover. Copy Text is in the task’s menu.
- After updating, restart Claude Desktop and open Claude Code sessions: until then they use the tools of the previous Peasy and can’t mark a task as in progress.
