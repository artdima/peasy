- Peasy now works with Claude. Claude Code adds the tasks only you can do, with a note and a link, to the project named like its folder.
- Hand a task to Claude with `@claude` in its title or Hand to Claude in its menu. Claude marks it as in progress, then finishes it with a note or hands it back with a question.
- Tasks show their notes. Choose Note… in a task's menu to write your own.
- Settings let Claude read only or make changes, and choose which Claude notifications to get.
- The sprout and the project counts leave out the tasks handed to Claude.
